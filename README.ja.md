# Auday Skill

[English](README.md) · [简体中文](README.zh-CN.md) · [日本語](README.ja.md)

Auday が知っていることを、あなたのワークフローへ。

いつものデスクトップ AI アシスタントで会話を探し、記憶どうしを結びつけ、プロジェクトの概要をまとめる。Mac の計算資源を使って録音を詳しく分析することもできます。iPhone のデータへのアクセスは常に読み取り専用で、利用する情報には出典が保持されます。

このリポジトリで配布するのはデスクトップ用 Skill のみです。Swift コードは Bonjour による検出、TLS 接続、Keychain へのアクセスを担当する macOS クライアントであり、iPhone アプリのコードではありません。iPhone の画面と実データのエクスポート処理は Auday アプリのリポジトリで管理します。

## 現在の状態

本プロジェクトは、インストール可能な初期段階の macOS クライアントと Agent Skill です。「Connect to your workflow」に対応した Auday の iPhone 版が必要です。このリポジトリの Skill をインストールするだけでは、iPhone のデータにアクセスできません。現在 App Store で配布されているバージョンが接続に対応していることを保証するものでもありません。

クライアントの自動テストでは、実際のローカル TLS 接続、読み取り専用のアクセス範囲、完全なスナップショット同期、音声ダウンロードの中断からの復旧、整合性検証、オフライン検索を確認しています。実機 iPhone のネットワーク動作とアプリのバージョン互換性は別途検証が必要です。[実機テスト手順](docs/device-testing.md)を参照してください。

## デスクトップ Agent からインストールする

ローカルの Skill に対応したデスクトップ Agent を開き、次のように依頼してください。

> https://github.com/666ghj/auday-skill から、このアプリで使えるように Auday Skill をインストールしてください。利用可能であることを確認したら、iPhone の Auday への接続を案内してください。

Agent がこのリポジトリにアクセスできる必要があります。非公開の間は、既存の GitHub ログインを利用してください。アクセストークンを会話に貼り付けないでください。Skill の保存先やインポート方法はアプリによって異なり、リポジトリのクローンが成功しただけではインストール完了とはいえません。

Agent は、利用中のアプリに備わった Skill インストーラーを使用できます。動作が明確なローカルインストーラーも同梱しています。

```sh
python3 tools/install.py --destination ~/.agents/skills/auday
```

利用中のアプリが対応する保存先を指定してください。インストーラーがコピーするのは Skill の実行コード、参照資料、メタデータ、ライセンス、バージョン情報のみです。既存のインストールを上書きせず、ホストアプリの設定も変更しません。新しい Skill が認識されない場合は、ホストアプリを更新または再起動してください。

## iPhone に接続する

1. iPhone で「設定 → Connect to your workflow」を開きます。
2. 「すべてのテキスト」または「テキストと音声」を選び、接続を有効にします。どちらも読み取り専用です。
3. デスクトップ Agent に Auday への接続を依頼します。iPhone が生成した通信用パスワードはローカルの入力画面に入力し、チャットには送信しないでください。
4. 同期中は iPhone の接続ページを開いたままにし、取得した情報を Agent に活用してもらいます。

依頼の例：

- 「リリースについて、最終的に何を決めた？ 元の会話も示して。」
- 「今週のプロジェクトの会話から、引き継ぎ用の概要をまとめて。」
- 「今日の記憶を振り返り、明確に約束したことと、今後の対応候補を分けて。」
- 「この録音を Mac で分析して。元の時間軸との対応関係は保持して。」

## 動作要件

- macOS 13 以降、Python 3.9 以降、および Swift 5.9 以降を含む Xcode Command Line Tools。
- 接続プロトコルに対応した Auday の iPhone 版と、相互に通信できるローカルネットワーク。Apple のピアツーピア検出は実験的な機能で、通常の LAN 接続には不要です。
- 任意の音声分析機能：`ffmpeg`、`whisper-cli`、ローカルのモデル重み、および `uv` で管理する Python 3.11〜3.13 の話者分析用依存パッケージ。モデルは同梱せず、自動ダウンロードもしません。

基本的な接続とコンテキストの取得に、AI API キー、Auday のクラウドアカウント、クラウド中継サーバーは必要ありません。

## データとプライバシー

ネイティブの接続プログラムは、システムが生成した16文字の通信用パスワード、HKDF-SHA256、TLS 1.2 ECDHE-PSK、および ChaCha20-Poly1305 を使用します。任意の短いパスワードは受け付けず、証明書検証の回避や平文通信へのフォールバックも行いません。詳細と現時点の制約は[プロトコル文書](docs/protocol.md)を参照してください。

通信用パスワードは macOS Keychain に保存します。ローカルキャッシュはソースのチェックアウト先ではなく、ユーザーのアプリケーションデータ領域に保存します。まずテキストを同期し、音声は必要に応じて取得します。接続を無効にすると以後の読み取りを防げますが、別のデバイスにダウンロード済みのコピーを回収することはできません。

通信がローカルでも、クラウド型 AI アシスタントの推論までローカルで行われるとは限りません。タスクに必要な抜粋だけを返してください。完全にローカルなワークフローには、推論と後続のツールもローカルで動作する必要があります。

## 開発と検証

```sh
sh tools/git/install-hooks.sh
python3 tools/verify_public.py
python3 -m unittest discover -s tests -v
swift test --package-path scripts/link
swift test --package-path tests/native-peer
```

macOS のテストでは合成データを使い、実際に暗号化されたループバック接続を検証します。Keychain を使うテストは明示的に有効化してください：`AUDAY_TEST_KEYCHAIN=1 python3 -m unittest discover -s tests -p test_pairing.py -v`。標準のテストに実際の録音やモデルのダウンロードは不要です。

iPhone アプリは別のリポジトリで管理しています。`tests/native-peer` は合成データを使う macOS のループバックテスト用サーバーで、Skill のインストール対象には含まれません。iPhone のビルドターゲット、画面、実際のデータ取得処理は同梱していません。
